# צייד האוצרות

> אפליקציה עצמאית לאספנים, לא קשורה ל-Mattel, Inc. ולא מאושרת על ידה. Hot Wheels, Treasure Hunt ו-Super Treasure Hunt הם סימני מסחר של Mattel, Inc., ומוזכרים רק כדי לתאר מוצרים. האפליקציה לא משתמשת בלוגו, בגופנים, בעיצוב האריזות או בתמונות של אחרים.

אפליקציית טלפון (PWA) שסורקת סטנדים של הוט ווילס 1:64, מסמנת Treasure Hunt ו-Super Treasure Hunt, מראה שווי ואיפה למכור, ומתעדת קניות עם קבלה.

- **עצמאית וחינמית:** מתארחת ב-GitHub Pages. הזיהוי רץ על Gemini במסלול החינמי עם מפתח אישי שנשמר רק בטלפון.
- **עדכון אוטומטי:** ב-1 וב-15 לכל חודש, GitHub Actions מריץ את `scripts/update.mjs`. הוא מעדכן שער דולר (frankfurter.dev), רכבי TH/STH חדשים (164custom.com), ומחירים והיסטוריית מחירים (hwpriceguide.com). אחרי זה מתפרסמת גרסה חדשה. דוח כל ריצה נשמר ב-`data/report.md`.
- **האוסף שלי:** מצלמים רכבים פתוחים. כל רכב מקבל קטגוריה, נדירות ושווי, ומוצג בסטים, כולל רכבים חסרים (בשרטוט מקורי) ורשימת חיפוש.
- **הנתונים האישיים** (ממצאים, קניות, קבלות) נשמרים רק בטלפון. גיבוי מתוך ההגדרות.

## מבנה
- `index.html` – האפליקציה
- `data/db.json` – מאגר הרכבים, המחירים ושער הדולר
- `scripts/update.mjs` – העדכון הדו-שבועי (Node 20, בלי תלויות)
- `.github/workflows/update.yml` – תזמון ופרסום
- `sw.js`, `manifest.webmanifest`, `icons/` – התקנה למסך הבית ועבודה בלי רשת

## הפעלה ידנית של עדכון
בלשונית Actions בוחרים `update-and-deploy`, ואז Run workflow.
