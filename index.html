צייד האוצרות
צלם עמודה אחת או שתיים של הסטנד (6–8 קרטונים) ממרחק של כחצי מטר, ישר מול הקרטונים.

חיבור חד-פעמי למנוע הזיהוי החינמי

הזיהוי רץ על Gemini של גוגל במסלול החינמי, עם מפתח אישי שלך. בלי תשלום ובלי כרטיס אשראי. לוקח כ-2 דקות, פעם אחת:

  1. פתח את aistudio.google.com/apikey והתחבר עם חשבון הגוגל שלך.
  2. לחץ Create API key והעתק את המפתח.
  3. הדבק אותו כאן ולחץ "שמור ובדוק".

המפתח נשמר רק בטלפון שלך. במסלול החינמי גוגל רשאית להשתמש בתמונות שנשלחות לשיפור המוצרים שלה.

אודות ומשפטי

צייד האוצרות היא אפליקציה עצמאית לאספנים, ואינה קשורה ל-Mattel, Inc. או ליצרני הרכב ואינה מאושרת על ידם. Hot Wheels, Treasure Hunt, Super Treasure Hunt, Red Line Club ושמות הסדרות הם סימני מסחר של Mattel, Inc.; שמות דגמי הרכב שייכים ליצרניהם. השמות מוזכרים רק כדי לתאר את המוצרים. האפליקציה לא משתמשת בלוגו, בגופנים או בעיצוב האריזות של Mattel. התמונות באוסף הן תמונות שצילמת בעצמך, ורכבים שאין לך מוצגים בשרטוט מקורי עם קישור למקור. נתוני הרשימות והמחירים הם עובדות מאתרים ציבוריים, והם נאספים פעמיים בחודש תוך כיבוד robots.txt.
